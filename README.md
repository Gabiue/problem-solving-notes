# problem-solving-notes

Coding and SQL problem solutions with hand-traced reasoning. The goal is to understand the logic, not just pass the tests.

Each file is one problem, named `number-problem-name.extension`, with short notes in a comment at the top.

## How I study

1. Read the statement and restate it in my own words.
2. Trace the examples by hand before writing any code.
3. Write the solution.
