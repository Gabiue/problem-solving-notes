# problem-solving-notes

Coding, SQL and Databricks practice with hand-traced reasoning. The goal is to understand the logic, not just pass the tests.

## What's inside

| Folder | Content |
|---|---|
| `leetCode/Csharp/` | LeetCode solutions in C# |
| `leetCode/MySQL/` | LeetCode SQL solutions |
| `databricks-code-practice/` | Databricks exercises (Spark SQL, window functions, Delta Lake, ELT), solved as prep for the Databricks Data Engineer Associate exam |

## LeetCode

Each file is one problem, named `number-ProblemName.extension`, with a short summary in a comment at the top.

## Databricks

Exercises come from [Databricks Code Practice](https://github.com/jrlasak/databricks-code-practice) by Jakub Lasak (CC BY-SA 4.0). My solutions are written in the notebooks and synced through a Databricks Git folder. Some notebooks have a `*-topics.md` file listing the concepts to study.

## How I study

1. Read the statement and restate it in my own words.
2. Trace the examples by hand before writing any code.
3. Write the solution.
